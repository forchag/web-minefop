{% trans "Notre engagement" %}

{% blocktrans %}Le Ministère de l'Emploi et de la Formation Professionnelle s'attache à rendre ce site accessible au plus grand nombre, en s'appuyant sur les recommandations internationales WCAG 2.1 niveau AA.{% endblocktrans %}

{% trans "Mesures mises en œuvre" %}

  • {% trans "Un lien « Aller au contenu principal » en tête de chaque page." %}
  • {% trans "Une navigation entièrement utilisable au clavier, avec un indicateur de focus visible." %}
  • {% trans "Des contrastes de couleurs conformes au seuil de 4,5:1 pour le texte courant." %}
  • {% trans "Une structure de titres hiérarchisée et des repères ARIA sur les zones principales." %}
  • {% trans "Des alternatives textuelles pour les images porteuses d'information." %}
  • {% trans "Le respect du réglage système « animations réduites »." %}
  • {% trans "Une mise en page adaptative, lisible sur téléphone comme à l'impression." %}
  • {% trans "Un site bilingue français / anglais, la langue étant déclarée dans le code de chaque page." %}

{% trans "Limitations connues" %}

{% blocktrans %}Certains documents mis en téléchargement sont des reproductions de textes officiels au format PDF dont la version d'origine n'a pas été produite dans un format accessible. Une version alternative peut être demandée aux services du Ministère.{% endblocktrans %}
